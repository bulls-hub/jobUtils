# jobUtils
개인 개발용

기능 2에 대한 개발을 진행하려고 하는데
기능 2에서는 쇼츠 컨텐츠를 만드는데 필요한 정보를 입력을 하고 관련 내용을 목륵으로 관리할 수 있도록 하는 서브 페이지를 만들거야
서브 페이지는 쇼츠 컨텐츠 목록을 보여주고 쇼츠 컨텐츠 목록을 선택하연 컨텐츠의 내용을 보여주고 최종 쇼츠 컨텐츠를 바로 볼 수 있도록 하는 기능이 있으면 좋겠어
기능을 만들기 위해 아래 내용이 검토가 필요해
1. 주제를 가지고 gemini를 활용하여 내용을 만들기 위한 프롬프트 자동 생성하는 방법
2. 생성된 프롬프트를 가지고 영상을 만들기 위한 방법
3. 만들어진 영상을 유튜브 쇼츠에 업로드 하기 위한 해시태그와 관련 노출을 최대화 하기 위한 방법

위 내용을 검토해서 설계된 Data flow를 보여주고 개발전에 나에게 확인요청을해줘
